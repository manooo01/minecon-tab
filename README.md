# Minecon Tab (Fabric 1.21.11)

Shows a small cape icon next to the name and makes the name shimmer gold/white in the TAB list
for players with a Minecon 2011 / 2012 / 2013 / 2015 / 2016 cape.

## Build
1. JDK 21 + Gradle (or copy `gradlew`, `gradlew.bat` and the `gradle/` folder from the Fabric example mod).
2. `./gradlew build`  (or `gradle build`)
3. Jar is in `build/libs/minecon-tab-1.0.0.jar` (not the `-sources` one). Needs Fabric API in `mods/`.

## If the build complains
Version numbers are in `gradle.properties` — grab the newest 1.21.11 ones from https://fabricmc.net/develop.
